Luckfox Shell — Tab Bar Design Reference (2026)

Tài liệu lưu lại các thiết kế tab bar của ứng dụng Luckfox Shell (800×480, Qt 5.15 / linuxfb / RV1106). Tất cả 8 mẫu đều đặt tabbar dọc mép trái — đồng bộ với Design 3 đang chạy trên thiết bị — và sử dụng 5 app: photo, mic, dashboard, calendar, music (settings đã bỏ). Click trực tiếp vào demo bên dưới để cảm nhận hiệu ứng. Thông số chính xác theo bảng spec để tái dựng lại trong QML. Design 3 là bản đang chạy trên thiết bị.

Design 3 — CURRENT Vertical Tab Rail (bridge + squash)

Thanh tab dọc trái kiểu automotive dark theme: rail 72px nền #0e0e14 dính mép trái. Nút 52×52 radius 14 — normal transparent / hover #16161f / active gradient amber đặc #fbbf24→#d97706 + icon tối + phóng to búng. Điểm nhấn Bridge: thanh 20×5px amber vươn từ mép rail sang vùng nội dung, trượt dọc InOutCubic + co giãn spring mỗi lần đổi tab — nối "cây tab" với "nội dung". Icon squash khi nhấn, ripple từ điểm chạm, content trượt ngang trong sheet. Tooltip custom trượt vào khi hover. Icon SVG thật qua QtSvg (data-URI, đổi màu động), không shadow — tối ưu cho embedded. 5 nút canh giữa: top = (480-300)/2 = 90px.

// Bridge - nối rail với vùng nội dung (QML tương đương QPropertyAnimation)
Rectangle { id: bridge
  width: 20; height: 5; radius: 3; color: "#f59e0b"
  x: 70
  y: 90 + currentTab * 62 + 23.5
  transform: Scale { id: bridgeScale
    xScale: 1.0; origin.x: 0; origin.y: 2.5
    Behavior on xScale { NumberAnimation { duration: 320
      easing.type: Easing.OutBack; easing.overshoot: 1.8 } } }
  Behavior on y { NumberAnimation { duration: 340
    easing.type: Easing.InOutCubic } }   // = cubic-bezier(.65,0,.35,1)
}
// Re-bung bridge mỗi lần đổi tab:
Connections {
  target: root
  function onCurrentTabChanged() {
    bridgeScale.xScale = 0          // restore 0, Behavior re-animate về 1
  }
}

Design 1 Floating Glass Dock (thanh dọc trái, 5 tab)

Kiểu "liquid glass" của xe điện hiện đại (Rivian R2 / Tesla launcher) kết hợp chỉ số trượt của trình duyệt (Chrome / Arc). Dock nổi dọc mép trái, tab active được đánh dấu bằng viên thuốc (pill) trượt nảy dọc theo chiều cao + glow accent + icon trắng sáng. Kích thước: dock 76×356px (5 tab 60px, gap 8, padding 12), canh giữa top = 62px.

Design 4 Vertical Glass Dock (kiểu CarPlay / Android Auto)

Dock kính nổi dọc mép trái kiểu CarPlay: kính tối rgba(16,24,42,.88) kích thước 68×308px radius 24, mép trái có vệt sáng highlight 1px rgba(255,255,255,.08) giả "cạnh kính". Tab active được đánh dấu bằng icon trắng phóng to 1.18× + quầng sáng tròn teal + chấm neon 6×6px trượt dọc sát mép phải của dock (spring OutBack overshoot 1.6). Thao tác: hover đẩy icon sang phải 4px kèm wash trắng 6% (tab nghỉ); press icon co 0.80 trong 90ms; click rê chấm neon + đổi icon, ripple teal bung từ điểm chạm. Màu: accent #4ecdc4, icon active #ffffff, icon nghỉ #5d6a85. Dock trượt vào từ mép trái + fade khi vào màn hình 500ms. Canh giữa dọc: top = (480-308)/2 = 86.

Design 5 Cyberpunk Neon Rail (góc cắt + dải sáng)

Rail dọc trái mood cyberpunk: nền gần đen #05060a phủ lưới grid cyan 4.5% (24px), nút icon hình lục giác cắt 4 góc 12px (clip-path). Tab active phủ gradient cyan #22d3ee → indigo #6366f1 + viền sáng + aura neon 64px phía sau; icon tối #060913. Điểm nhấn: dải sáng dọc 3×44px sát mép phải rail — trượt spring + "búng" scaleY mỗi lần đổi tab; mép phải rail là sọc gradient cyan→fuchsia 1px. Thao tác: hover nền #101522 + icon sáng; press nút nghiêng skewX(-4°) co 0.94; click dải sáng di chuyển + ripple cyan bung từ điểm chạm. Nội dung bên phải đổi theo tab (ghost chữ + tiêu đề neon). Canh giữa dọc: top = (480-280)/2 = 100.

Design 6 Arc Wheel — bánh xe xoay chọn tab (trái)

Launcher bánh xe dọc mép trái: 5 icon đặt quanh vòng tròn 140px (chia 72°/icon), click làm cả vòng xoay để icon được chọn quay về đỉnh 12 giờ — cảm giác xoay đồng hồ analog. Xoay 420ms OutBack overshoot 1.2; icon luôn đứng thẳng nhờ bù góc ngược (counter-rotate). Icon active phóng to 1.25× trắng #ffffff, chấm fuchsia 8px đánh dấu vị trí trên vành; các icon khác #6d6a85. Trung tâm là chip overview (icon + nhãn tab 8.5px #c9c2ff). Màu: violet #a78bfa→fuchsia #e879f9, nền radial #1a1236 → #070512 + quầng 260px. Vòng xoay scale-in + fade khi vào màn hình 450ms. Canh giữa dọc: top = 156, left = 26.

Mã nguồn QML (rút gọn)

Cấu trúc cốt lõi — phần chưa đủ lấy nguyên bản tại qml/shell.qml. Icon vẽ bằng Canvas (nhẹ cho RV1106, không dùng blur/shadow).

// ============ Design 2: Left Tab List (dọc trái) ============
Item { id: rail; x: 10; y: 64; width: 112; height: 318

  // Chỉ số trượt (gạch trái)
  Rectangle { id: indLine
    width: 3; height: 28; radius: 1.5; color: accentColor
    anchors.left: parent.left; anchors.leftMargin: -1
    y: 21 + currentTab * 62
    Behavior on y { NumberAnimation { duration: 320
      easing.type: Easing.OutBack; easing.overshoot: 1.5 } }
  }

  Column { anchors { left/right; top: 8 }
    spacing: tabSpacing
    Repeater { model: tabModel
      delegate: Item { width: 96; height: 54
        property bool active: index === root.currentTab
        // pill nền active + Canvas icon + label + MouseArea
      }
    }
  }
}

// Sheet nội dung nổi
Rectangle { id: sheet; radius: 18; color: "#0f1728"
  anchors { left: parent.left; leftMargin: 132; right: parent.right
            rightMargin: 12; top: parent.top; topMargin: 64
            bottom: parent.bottom; bottomMargin: 12 }
  Loader { id: contentLoader; anchors.fill: parent; anchors.margins: 8 }
}

Ghi chú triển khai

  • Quy ước mới: tất cả 8 mẫu đều đặt tabbar dọc mép trái để đồng bộ với Design 3 đang chạy; số lượng app cố định 5: photo, mic, dashboard, calendar, music (settings đã bỏ) — mọi công thức canh giữa dọc dùng top = (480 - tổng chiều cao)/2.
  • RV1106 + linuxfb: tránh DropShadow/MultiEffect (không có/đắt). Glow & halo dùng Rectangle phủ màu alpha chồng lớp — rẻ và luôn chạy.
  • Canvas + màu: Canvas không tự repaint khi property thay đổi → dùng onIconColorChanged: requestPaint().
  • Icon: vẽ stroke 2px, round cap/join; tỷ lệ s = w/26 để scale theo mọi kích thước.
  • Revert tab: tab chưa implement (2..4) tự quay về tab cũ trong onCurrentTabChanged.
  • Font: thiết bị chỉ có DejaVu (/usr/share/fonts/dejavu/) — không dùng Arial trong Canvas ctx.font.
  • Easing spring: OutBack với overshoot 1.4–1.8 tạo cảm giác "nảy" đặc trưng của tab hiện đại; dùng cubic-bezier(.34,1.56,.64,1) nếu làm HTML/CSS tương đương.
  • Đổi thiết kế: Design 1 đã lưu ở lịch sử git (bản trước). Muốn quay lại: restore qml/shell.qml cũ và dùng spec bảng Design 1.
