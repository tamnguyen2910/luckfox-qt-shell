Tab Bar Mẫu 2 — "The Bridge" (solid dark + mint neon)

Thiết kế tab bar dọc đang chạy trên Luckfox Shell (800×480, Qt 5.15 / linuxfb / RV1106). Nền tối đặc (tuyệt đối không blur/glass), tab squircle, active = nền Accent đặc + phóng to búng, điểm nhấn là cầu nối (Bridge) vươn từ tab active vào vùng nội dung. Demo tương tác dưới đây — click để chuyển tab (có ripple), hover xem trạng thái.

Mã QML cốt lõi (qml/shell.qml)

// ---------- THE BRIDGE ----------
Rectangle { id: bridge
  z: 15; width: 22; height: 4; radius: 2; color: "#2dd4bf"
  x: railWidth - 2
  y: bridgeY(currentTab)                      // = 16 + idx*58 + 22
  transform: Scale { id: bridgeScale
    xScale: 1.0; origin.x: 0; origin.y: 2
    Behavior on xScale { NumberAnimation { duration: 320
      easing.type: Easing.OutBack; easing.overshoot: 1.8 } }
  }
  Behavior on y { NumberAnimation { duration: 340
    easing.type: Easing.OutBack; easing.overshoot: 1.6 } }
}
// Re-bung bridge mỗi lần đổi tab:
Connections {
  target: root
  function onCurrentTabChanged() {
    bridgeScale.xScale = 0
    Qt.callLater(function() { bridgeScale.xScale = 1 })
  }
}

// ---------- TAB ITEM (squircle + ripple) ----------
Item { width: 48; height: 48
  property bool active: idx === root.currentTab
  property bool hovered: tabMouse.containsMouse
  scale: active ? 1.06 : 1.0
  Behavior on scale { NumberAnimation { duration: 300
    easing.type: Easing.OutBack; easing.overshoot: 1.8 } }

  Rectangle { // nền
    anchors.fill: parent; radius: 16; clip: true
    color: active ? "#2dd4bf"
         : hovered ? Qt.rgba(1,1,1,0.03) : "transparent"
    Behavior on color { ColorAnimation { duration: 220 } }

    Rectangle { id: ripple    // vòng tròn từ điểm chạm
      width: 64; height: 64; radius: 32; visible: false
      color: Qt.rgba(0.18, 0.83, 0.75, 0.30); scale: 0.1; opacity: 1
      ParallelAnimation { id: rippleAnim
        NumberAnimation { property: "scale"; from: 0.1; to: 1.6; duration: 500; easing.type: Easing.OutCubic }
        NumberAnimation { property: "opacity"; from: 1; to: 0; duration: 500; easing.type: Easing.OutCubic }
      }
    }
  }
  Image { // icon SVG: #4a4a5e / #8a8a9e / #052018
    source: root.svgIcon(tabModel[idx], active ? "#052018" : hovered ? "#8a8a9e" : "#4a4a5e", 20)
  }
  MouseArea { id: tabMouse
    onClicked: currentTab = idx
    onPressed: { ripple.x = mouse.x - 32; ripple.y = mouse.y - 32
                 ripple.visible = true; rippleAnim.restart() }
  }
}

// ---------- CONTENT SLIDE (StackLayout, trang mới trượt phải->trái) ----------
StackLayout { id: pages; currentIndex: currentTab
  Item {   // mỗi page là 1 con, bên trong mới animate transform
    transform: Translate {
      x: pages.currentIndex === 0 ? 0 : 60
      Behavior on x { NumberAnimation { duration: 420
        easing.type: Easing.OutBack; easing.overshoot: 1.2 } }
    }
    Rectangle { anchors.fill: parent; radius: 14; gradient: "...gradient tối riêng..." }
  }
}

Điều chỉnh khi ghép vào app

  • Không cần GPU: mẫu này không dùng blur/glass/shadow — chạy mượt trên software renderer RV1106, bỏ luôn kiểm tra gpuAccelerated.
  • Bridge theo tab scroll: nếu list tab cuộn được, y của bridge phải tính qua mapToItem (xem mẫu tooltip cũ) — bản này dùng Column cố định nên dùng công thức bridgeY(i).
  • Spring easing: OutBack + overshoot 1.2–1.8 cho scale/y/x; CSS tương đương cubic-bezier(.34,1.56,.64,1).
  • Icon SVG: giữ svgIcon() data-URI qua QtSvg; đổi màu = đổi data-URI (Image reload, không cần repaint Canvas).
  • Ripple trên touch: onPressed kích hoạt cả chuột lẫn cảm ứng — lấy tọa độ từ mouse.x/y.
